1. Strict Validation vs. Silent Coercion

In secure software design, silent input modification (e.g. converting lowercase or stripping spaces) can alter the intended message without caller consent and invalidate message integrity. Rejecting invalid characters with their exact position ensures fail-fast validation.

2. Why “+ 26” is Required in Decryption

JavaScript's % operator calculates truncated division remainder rather than mathematical modulo. For example, decrypting B (pos 1) with k=3 gives 1 - 3 = -2. In JavaScript, -2 % 26 = -2. Since -2 ≡ 24 (mod 26), adding 26 ensures the operand is positive before applying the modulo ((1 - 3 + 26) % 26 = 24, which is Y).

3. Educational Purpose and Vulnerability

With only 26 possible keys (|K| = 26), the Caesar cipher offers zero security against ciphertext-only attacks. An adversary can test all 26 shifts in microseconds or analyze single-letter frequency distribution.
